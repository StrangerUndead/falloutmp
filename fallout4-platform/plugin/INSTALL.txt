FalloutMP client (test build)
=============================

This build connects every system of a FalloutMP server to the game:
movement and animations, appearance and character creation, inventory
and equipment, stats, levels and perks, chems and effects, combat
(shots, hits, damage, death), power armor, workshops and settlements,
crafting and modding, locks, terminals and hacking, the map and fast
travel, and time and weather.

It has not been tested in the game yet. Expect problems: every system
can be switched off on its own (see "Settings") so one broken part
doesn't stop the rest, and the probe (below) records what the developers
need to fix things.

Requirements
- Fallout 4, current Steam or GOG version (1.11.x, the Anniversary
  Edition update). The older 1.10.984 and 1.10.163 versions are not
  supported by this build.
- F4SE for your game version: https://f4se.silverlock.org
- Address Library for F4SE Plugins (the version for 1.11.x):
  https://www.nexusmods.com/fallout4/mods/47327
- Recommended: Buffout 4 (crash logs name the failing function).

Install
1. Copy the Data folder from this archive into your Fallout 4 folder
   (the one with Fallout4.exe). You should end up with:
     Data\F4SE\Plugins\FalloutMP.dll
     Data\F4SE\Plugins\FalloutMP.example.json
     Data\F4SE\Plugins\FalloutMP\falloutmp-client.js
2. Rename FalloutMP.example.json to FalloutMP.json (first install only),
   open it and enter your server:
     "server-ip": "203.0.113.10", "server-port": 7777
3. Start the game with f4se_loader.exe.
4. Load a save you don't mind (or start a new game). The client connects
   when the save has loaded. A new character on the server opens the
   character editor first. Use a separate save for multiplayer.

Updating: copy the new Data folder over the old one. The archive has no
FalloutMP.json, so your settings and your "profile-id" (your character
on the server) are kept. Back up FalloutMP.json anyway.

The full guide, including running a server, is
docs/falloutmp/guides/install-guide.md in the FalloutMP repository.

First run: the probe (please do this once)
1. In FalloutMP.json set "probe": true. No server is needed.
2. Load a save and wait about 5 seconds. A test character appears next
   to you for a moment.
3. When the message "recording 60 s" appears: walk, run, sprint, sneak,
   jump, draw your weapon, aim, fire, reload, open the Pip-Boy.
4. When it says "probe finished", send these files:
     Data\F4SE\Plugins\FalloutMP-probe.json
     Documents\My Games\Fallout4\F4SE\FalloutMP.log
5. Set "probe" back to false.

Settings in FalloutMP.json
- server-ip, server-port: the server to join.
- profile-id: your character on this server (generated once).
- features: switch a system off with false, e.g. "combat": false.
  Names: session, movement, puppets, animation, appearance, inventory,
  equipment, actorValues, progression, effects, combat, powerArmor,
  workshop, locks, map, world.
- puppet-ai: how other players' characters are kept still: "package"
  (default), "restrained", or "off".
- puppet-move: "native" (default) or "papyrus". Try "papyrus" if other
  players don't move on your screen.
- puppet-warp: "controller" (default) or "reference".
- puppet-base: base NPC used for other players, default "0x7" (a copy of
  your character, replaced by their own face once it arrives).

Troubleshooting
- Logs: Documents\My Games\Fallout4\F4SE\FalloutMP.log (plugin) and,
  with Papyrus logging on, Documents\My Games\Fallout4\Logs\Script\
  Papyrus.0.log. To turn Papyrus logging on, add to
  Documents\My Games\Fallout4\Fallout4Custom.ini:
    [Papyrus]
    bEnablePapyrusLogging=1
    bEnableLogging=1
    bEnableTrace=1
    bLoadDebugInformation=1
- The game crashes on load: remove FalloutMP.dll and check F4SE and the
  Address Library match your game version. Send the Buffout 4 crash log.
- A system misbehaves: switch it off in "features" and send the logs.
- "Can't reach the server": check the address, and that the server's
  firewall allows UDP 7777.
- "The server refused the connection: Invalid password": the server and
  the client are different versions, or the server isn't a Fallout 4
  server.
